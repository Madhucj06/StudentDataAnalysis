# Student Data Analysis

A Python project to analyze student marks and attendance using CSV data.

## Features
- Reads student information from a CSV file.
- Analyzes students' marks.
- Calculates average marks.
- Processes attendance data.
- Generates analysis results.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- CSV File Handling

## Project Files
- `analysis.py` – Main Python program.
- `students.csv` – Sample student dataset.

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Install the required Python libraries.
4. Open the terminal in the project folder.
5. Run:

   `python analysis.py`

## Project Purpose
This project was developed to practice Python programming, CSV file handling, and basic data analysis.
